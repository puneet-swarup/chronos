# Support Chronos

Chronos is a local-first, privacy-respecting Android automation app. If it saves you
time, consider supporting its development.

## Ways to help

- Report bugs and request features via GitHub Issues.
- Improve documentation or translate strings.
- Test on a device with aggressive background restrictions and report what breaks.
- Sponsor ongoing development (see below).
- Star the repository — it helps others find it.

## Donation channels

| Channel | Where |
|---------|-------|
| GitHub Sponsors | <https://github.com/sponsors/puneet-swarup> |
| Ko-fi | <https://ko-fi.com/puneetswarup> |

## What donations fund

- Device compatibility testing across OEMs.
- On-device AI model tuning and benchmarking.
- Reliability work: reboot recovery and OEM background restrictions.

Donations are optional. Chronos remains fully usable without them and without any
cloud account.

## Getting help

- Usage and design questions: open an issue.
- Security problems: follow [SECURITY.md](https://github.com/puneet-swarup/chronos/blob/main/SECURITY.md)
  and report privately, not in a public issue.
