# Support Chronos

Chronos is developed as a local-first, privacy-respecting automation app. If it
saves you time, consider supporting its development.

## Ways to help

- Report bugs and request features via GitHub Issues.
- Improve documentation or translate strings.
- Sponsor ongoing development (see options below).
- Star the repo - it helps others discover Chronos.

## What donations fund

- Device compatibility testing across OEMs.
- On-device AI model tuning and benchmarking.
- Reliability work: reboot recovery, OEM background restrictions.

Donations are optional. Chronos remains fully usable without them and without
any cloud account.
